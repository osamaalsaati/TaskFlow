# TaskFlow

**لوحة مهام عربية لتنظيم العمل من الفكرة إلى الإنجاز.** تعرض المهام في ثلاث قوائم واضحة: **To Do** و**In Progress** و**Done**، وتتيح نقل البطاقات وترتيبها بالسحب والإفلات. الواجهة متجاوبة وتعمل على الحاسوب والهاتف.

> An Arabic, responsive task board built with ASP.NET Core 8 and plain JavaScript.

## الميزات

- إنشاء المهام وتعديلها وحذفها، مع عنوان ووصف وأولوية وتاريخ استحقاق اختياري.
- نقل المهام بين القوائم وتغيير ترتيبها داخل كل قائمة بالسحب والإفلات.
- دعم السحب بالماوس، والسحب من المقبض على الهاتف، والتحريك بلوحة المفاتيح.
- البحث الفوري عن المهام وعرض عدد المهام ونسبة الإنجاز.
- حفظ المهام وترتيبها تلقائيًا في `localStorage`، واستعادتها بعد تحديث الصفحة.
- واجهة عربية باتجاه RTL ومتجاوبة مع أحجام الشاشات المختلفة.

## التقنيات

| الجزء | التقنية |

## التشغيل محليًا

تحتاج إلى [.NET SDK 8](https://dotnet.microsoft.com/download/dotnet/8.0) ومتصفح حديث.

```powershell
git clone https://github.com/osamaalsaati/TaskFlow.git
cd TaskFlow
dotnet run
```

افتح العنوان الذي يظهر في الطرفية؛ الإعداد الافتراضي هو **http://localhost:5020/**. لا يحتاج المشروع إلى قاعدة بيانات أو مفاتيح API أو تثبيت حزم JavaScript.

للتحقق من البناء دون تشغيل الموقع:

```powershell
dotnet build
```

## الاستخدام

1. اضغط **مهمة جديدة** لإضافة بطاقة إلى قائمة **To Do**.
2. اسحب البطاقة إلى قائمة أخرى، أو غيّر مكانها داخل القائمة نفسها. على الهاتف استخدم مقبض السحب **⠿**.
3. استخدم زري التعديل والحذف في البطاقة عند الحاجة، أو ابحث عنها من حقل البحث.

للوحة المفاتيح: ركّز مقبض السحب، اضغط **مسافة** لتحديد البطاقة، ثم استخدم الأسهم لنقلها، واضغط **مسافة** مرة أخرى للإفلات. تظهر بعض المهام النموذجية عند أول فتح ويمكن تعديلها أو حذفها.

## أين تُحفظ المهام؟

تُحفظ البيانات في متصفحك على الجهاز نفسه. لا تتزامن المهام بين الأجهزة أو المستخدمين، وقد تُحذف عند مسح بيانات الموقع من المتصفح. يعمل ASP.NET Core هنا على تقديم ملفات الواجهة؛ لا توجد في هذه النسخة واجهة API للمهام أو قاعدة بيانات أو حسابات مستخدمين.

## بنية المشروع

```text
TaskFlow.csproj                 مشروع ASP.NET Core 8
Program.cs                      إعداد تقديم الملفات الثابتة
Properties/launchSettings.json  عنوان التشغيل المحلي
wwwroot/index.html              الصفحة الرئيسية
wwwroot/styles.css              التصميم المتجاوب
wwwroot/app.js                  إدارة المهام والسحب والتخزين المحلي
```
